# @dsh-plugin-edu/a2ui-protocol

Shared A2UI v0.9.1 types, catalog definitions, guard validation, and surface lifecycle reduction for DeepSeek Harness component libraries.

This package is for component-library authors. It is installed transitively by the A2UI workspace during development and can be added explicitly when a custom library imports protocol types or catalog helpers.

```bash
pnpm add @dsh-plugin-edu/a2ui-protocol@beta
```

The package is ESM and requires Node.js 22 or later.
